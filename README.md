# Hand Tracking Project

A real-time hand tracking project built using Python, OpenCV, and MediaPipe.

## About The Project

This is my first attempt at building a computer vision project. I chose hand tracking as an entry point because MediaPipe makes detecting hand landmarks straightforward and fast to implement, while OpenCV handles the live webcam feed seamlessly.

The goal is to get hands-on experience with:
- Video capture and frame processing in OpenCV
- Extracting 21 3D hand landmarks in real time
- Understanding coordinate mapping for basic gesture recognition

## Tech Stack

- **Python**
- **OpenCV**
- **MediaPipe**
